# ВКР по Football Prognoz

Инструкция для диплома. Тема приложения: настольный статистический прогноз исходов футбольных матчей (1 / X / 2). Это **не** букмекер и не совет ставить деньги.

Оглавление из `oglavlenie_vkr.docx` подходит. Не подменять локальную модель вызовом ChatGPT «кто победит».

## Тема на титуле

Рекомендуемая формулировка: «Разработка настольного приложения статистического прогнозирования исходов футбольных матчей».

Не формулировать как тотализатор или «систему ставок».

4. Глава 3. Реализация и оценка  
   - 3.1. Загрузка данных и прогноз  
   - 3.2. Графический интерфейс и пояснение  
   - 3.3. Тестирование и качество прогноза  
5. Заключение

7. Приложения А–Д: ТЗ, схема БД, руководство, листинги, примеры прогнозов  

Объём по черновому оглавлению (~30–32 страницы основного текста) — нижняя граница. Если кафедра требует 40–60 страниц, расширять 1.1, 2.2 (формулы) и 3.3 (таблицы метрик), а не листинги в главах.

## Жёсткие запреты для текста ВКР

- Не утверждать, что ChatGPT считает исход матча.  
- Не обещать прибыль от ставок. Дисклеймер обязателен.  
- Не выдавать кэш SQLite за промышленную СУБД.  
- Список литературы: первоисточники (Elo, Maher / Dixon–Coles, документация football-data.org v4, Flet, ГОСТ на ТЗ). Не один Хабр. Три страницы списка — мало.
