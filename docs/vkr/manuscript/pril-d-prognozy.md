# Приложение Д

## Примеры прогнозов

Примеры ниже иллюстрируют различие факта, оценки и вывода. Они не являются советом ставить деньги.

### Д.1 Эталонный срез признаков (модульные тесты)

Исходные оценки:

– рейтинги Эло: хозяева 1600, гости 1580;
– средние голы за пять матчей: хозяева 2,0 забитых и 0,8 пропущенных; гости 2,2 и 1,0;
– число завершённых матчей лиги в кэше: 20.

Вывод модуля (сверено с реализацией):

– вероятности 1 / X / 2 ≈ 0,4817 / 0,2442 / 0,2741;
– предварительный счёт: 1:1;
– вероятность клетки ≈ 0,112;
– ожидаемые голы для предварительного счёта: 1,50 : 1,50.

Для сравнения: наивная эвристика с округлением тех же $K_1$ и $K_2$ дала бы 2:1.

### Д.2 Учебная точка на sample_results.csv

Матч Chelsea – Man City, дата 21.09.2024, факт: 0:2, исход 2.

Упрощённый проход вперёд по шести строкам образца (обновление рейтингов только после прогноза) дал:

– смесь: p ≈ 0,2468 / 0,2161 / 0,5371, ярлык 2;
– только Эло: p ≈ 0,4551 / 0,2486 / 0,2963, ярлык 1;
– эвристика ceil/floor: ярлык 2;
– Brier смеси 0,3219; Brier Эло 0,7642; Brier равномерной базы 0,6667;
– log-loss смеси 0,6216; log-loss Эло 1,2165; log-loss равномерной базы 1,0986.

Это учебный пример на N = 1, не качество чемпионата.

### Д.3 Как читать карточку пользователю

1. Сначала три процента исхода.
2. Затем предварительный счёт вместе с процентом клетки.
3. Затем форма, Эло, очные встречи и таблица как контекст.
4. Затем текст пояснения, если он есть.
5. Дисклеймер действует на все числа экрана.
