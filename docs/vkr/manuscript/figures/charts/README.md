# Графики для ВКР

## Сделано

- `elo-expectation.png` — ожидание Эло хозяев от разницы рейтингов (дом +80, делитель 400).
- `poisson-grid.png` — сетка Пуассона 0…8 для учебного примера из `docs/FORECAST.md` § 6 / `tests/test_predictor.py`.
- `outcome-bars.png` — вероятности 1 / X / 2 того же примера (`Predictor`, смесь 65/35).

Числовой пример:

- Elo хозяев 1600, гостей 1580;
- средние голы за 5 матчей: хозяева 2,0 / 0,8; гости 2,2 / 1,0;
- `sample_matches = 20`;
- λ_дом ≈ 1,63; λ_гости ≈ 1,17;
- итог 1X2 ≈ 48,2 % / 24,4 % / 27,4 %.

## Не сделано: `baseline-compare.png`

Файл `data/samples/sample_results.csv` содержит только **6** завершённых матчей (плюс заголовок). Этого недостаточно, чтобы честно посчитать и сравнить Brier / log-loss для смеси Elo+Пуассон и эвристики «5 матчей» на той же выборке: для формы за 5 игр и калибровки нужна более длинная история. Метрики не выдумывались; график сравнения пропущен намеренно.
