# Как вычитывать текст о прогнозе

Этот каталог — не код и не «ещё одна спецификация». Сюда вынесен **связный текст** для научного руководителя, нормоконтроля и литературной правки.

| Файл | Для кого | Что внутри |
| --- | --- | --- |
| [tekst-na-vychitku.md](tekst-na-vychitku.md) | вычитывающий | Главы 1.1 и 2.2 плюс фрагмент 3.2. Сплошная речь, формулы, пример. Имена модулей в основном тексте нет. |
| [../FORECAST.md](../FORECAST.md) | разработчик | Как считает код. Сверять формулы, не править стиль. |
| [../VKR.md](../VKR.md) | автор диплома | Каркас оглавления и запреты. |

## Как править

1. Открыть только `tekst-na-vychitku.md`. Читать сверху вниз, как главу в Word.
2. Комментировать смысл, термины, повторы, дыры в логике и спорные утверждения.
3. Формулы в `$...$` / `$$...$$` при переносе в Word превратить в редактор формул. Не удалять их «для красоты»: без них глава пустая.
4. Блоки *«На вычитку»* — вопросы автору и кафедре. После ответа блок убрать, в чистовик он не идёт.
5. Приложение в конце файла — шпаргалка «формула ↔ код». В главу диплома не копировать.

## Чего в этом тексте нет и не надо дописывать «от себя»

- обещания прибыли от ставок;
- фразы вроде «ChatGPT определяет победителя»;
- xG, травмы, составы — в бесплатном API их нет, модель их не берёт;
- PostgreSQL вместо SQLite-кэша;
- наивное округление «хозяевам вверх, гостям вниз» как основной метод.

Вычитанный текст переносится в документ ВКР по оглавлению из [VKR.md](../VKR.md): § 1.1, § 2.2, кусок § 3.2. Инженерный [FORECAST.md](../FORECAST.md) после правки смысла нужно сверить: цифра в дипломе и цифра на экране должны совпадать.
