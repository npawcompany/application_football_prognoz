# Football Prognoz — описание продукта

**Название:** Football Prognoz  
**Репозиторий:** `application_football_prognoz`  
**Платформы:** Windows 10/11 (64-bit) и macOS 12+  
**Стек:** Python 3.11+, Flet, httpx, pandas, SQLite, scikit-learn. LLM только для текста.

## Что это

Десктоп-приложение (нативное окно, не браузер). Пользователь выбирает лигу, видит предстоящие матчи, получает вероятности исхода **1 / X / 2** и короткий текстовый разбор «почему так».

Числа считает локальная статистическая модель (Elo + Poisson). Языковая модель не выдумывает счёт — она объясняет уже посчитанные вероятности и факты из кэша. Что считается фактом и как из него получается 1X2 — [FORECAST.md](FORECAST.md).

## Что это не является

- Не букмекер и не гарантия ставки.
- Не live-сканер счёта. На бесплатном плане football-data.org счёт и расписание могут быть с задержкой.
- Не сбор персональных данных: приложению они не нужны.

В интерфейсе всегда есть подпись: прогноз статистический, это не совет ставить деньги.

## Пользовательский сценарий

1. Запуск окна приложения.
2. Ввод ключей в **Настройках** (football-data.org, опционально OpenAI). Ключи только в локальном `.env`.
3. Выбор лиги из 12 бесплатных соревнований football-data.org.
4. Список ближайших матчей: дата, хозяева, гости, статус.
5. Клик по матчу: вероятности 1X2, форма команд, H2H, место в таблице; ниже — AI-пояснение по этим фактам.
6. История и фичи кэшируются в SQLite, чтобы не жечь лимит 10 запросов/мин.

## Источники данных

- **football-data.org** REST v4 — календарь, результаты, таблицы (основной live-контур).
- **football-data.co.uk** CSV — длинная история и коэффициенты для обучения модели.
- **API-Football** — не в первой версии; опциональный второй этап.
